## Sistema financeiro pessoal

Sistema desenvolvido para controle de finanças pessoais.

## Finansee é uma plataforma para controle de finanças pessoais.

### Desenvolvido por [Diego Martins](https://github.com/DGTJS)

## Instalação

```bash
npm install
```

## Execução

```bash
npm run dev

```

# Stacks do projeto

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [Vite](https://vitejs.dev/)
- [Shadcn/ui](https://ui.shadcn.com/)
- [PostgreSQL](https://www.postgresql.org/)
- [Drizzle](https://drizzle-orm.org/)
- [Better Auth](https://github.com/nextauthjs/next-auth)
- [Zod](https://zod.dev/)
